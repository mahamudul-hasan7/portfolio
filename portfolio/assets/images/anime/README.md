# Anime Images

এখানে তোমার favourite anime-র images রাখো।

## Required filenames:

| File Name      | Anime                          |
|----------------|-------------------------------|
| `aot.jpg`      | Attack on Titan                |
| `naruto.jpg`   | Naruto Shippuden               |
| `deathnote.jpg`| Death Note                     |
| `sao.jpg`      | Sword Art Online               |
| `fmab.jpg`     | Fullmetal Alchemist: Brotherhood |
| `ylia.jpg`     | Your Lie in April              |

## Notes:
- Recommended size: **400×200** বা **16:9** ratio
- Format: `.jpg` or `.png` (`.jpg` preferred for smaller size)
- নতুন anime যোগ করতে চাইলে আমাকে বলো!
